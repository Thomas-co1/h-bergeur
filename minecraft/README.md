# Plugin Minecraft Prometheus Exporter

## Installation

1. Téléchargez le plugin depuis : https://github.com/sladkoff/minecraft-prometheus-exporter/releases
2. Prenez la dernière version `.jar` (ex: `minecraft-prometheus-exporter-2.5.0.jar`)
3. Placez le fichier `.jar` dans le dossier `plugins/`

Le plugin exposera les métriques sur le port 9225.
